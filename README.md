A machine learning project built in a Jupyter Notebook environment to predict housing prices using historical regression data. This model splits provided training data to validate performance before generating a final submission set.

##  Project Overview

This repository contains a full end-to-end data science workflow designed to handle data exploration, feature engineering, model training, and validation for predicting real estate market prices. 

### Key Constraints Implemented:
* **80/20 Train-Test Split:** Splitting source data dynamically to protect against overfitting.
* **Evaluation Plotting:** Strict evaluation mapping with **House ID** on the X-axis and **Predicted Price (\$)** on the Y-axis.
* **Pipeline-Ready:** Prepares an automated export structure matching `sample_submission.csv` requirements.

   Open the repository folder in VS Code or run standard Jupyter locally:
   ```bash

   ```

---

##  Model Workflow

The notebook progresses sequentially through these core technical milestones:

1. **Data Loading:** Parsing internal files via `pandas`.
2. **Exploratory Data Analysis (EDA):** Identifying correlation matrices and distribution trends.
3. **Data Splitting:** Executing an 80% train, 20% validation pipeline utilizing `train_test_split`.
4. **Model Selection:** Training a structural linear regression pipeline.
5. **Validation Visualization:** Mapping model performance explicitly on validation IDs.
6. **Submission Generation:** Testing against unlabeled target features and piping data into `submission.csv`.
